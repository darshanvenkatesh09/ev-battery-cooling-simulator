EV Battery Cooling System Simulator

An interactive Four-Wheeler EV Battery Thermal Management Simulator developed for understanding and demonstrating electric vehicle battery cooling systems using both hardware integration and software-based visualization.

Project Overview

This project simulates the thermal management system of an EV battery pack using real-time temperature monitoring, automatic cooling control, and coolant circulation mechanisms. The simulator demonstrates how overheating in EV battery systems can be detected and controlled using sensors, relays, coolant pumps, and radiator fans.

The project includes:

2D Interactive Thermal Management Simulation
3D EV Battery Cooling Visualization
Automatic Cooling Activation Logic
Real-Time Temperature Monitoring
Coolant Flow Simulation

Working Principle
Temperature sensors continuously monitor battery temperature.
When temperature exceeds 38°C:
Relay gets activated
Coolant pump turns ON
Radiator fan starts
Coolant circulates through aluminum cooling pipes.
Heat is dissipated and battery temperature reduces.
System returns to standby mode after cooling.
